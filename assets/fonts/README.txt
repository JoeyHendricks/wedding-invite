The faces in use:

  TT-Modernoir-Variable.woff2   section headings, day panels, venue names.
                                One variable file covers every weight.

  LaLuxes.otf                   the countdown figures, the small gold
                                "A celebration of love" line, the calendar
                                button. Loaded as .otf — no .woff2 exists.

  Blosta-Script.woff2           one line only: "are getting married".

  Cormorant Garamond            the couple's name everywhere, all body
                                copy, labels, dates, form fields. Comes
                                from Google Fonts, not this folder.

Caps-only, worth knowing before you assign one to a sentence:
  La Luxes, TT Modernoir and Abramo have no lowercase glyphs at all —
  lowercase letters map to the capitals. Only Blosta Script and
  Cormorant can set mixed case.

  Abramo Regular.woff2          NOT USED. Delete freely.
  Blosta-Regular.woff2          NOT USED. Blosta's companion face.
